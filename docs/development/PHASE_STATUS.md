# Phase status

> Research and educational use only. Not a medical device and not intended for clinical diagnosis or treatment.

| Phase | Implementation status | Validation |
| --- | --- | --- |
| Project vision and pipeline architecture | Stage catalog, typed component interface, experiment context, CLI, architecture notes, and animated README assets | Unit tests cover component substitution, reference order, and notice visibility through the CLI. |
| Advanced capabilities and technology direction | [Capability roadmap](CAPABILITIES.md) maps proposed features to validation gates and dependency choices | Documentation review and existing CLI regression checks. |
| Monorepo architecture | [Repository layout](../architecture/REPOSITORY.md), compatible core imports, contributor files, CI, and CLI container definition | Import compatibility, CLI checks, wheel installation, and Compose configuration validation. |
| Phase 1 foundation | [Runtime settings](FOUNDATION.md), JSON logging, seed handling, exceptions, CLI entry point, and developer tooling | Clean installation, unit and CLI integration checks, Ruff, mypy, pre-commit, and Compose configuration. |
| Phase 2 MRI data engine | [MRI ingestion](IMAGING.md), reviewed DICOM discovery and loading, RAS volume contracts, dataset validation, and local BraTS 2021 adapter | Synthetic NIfTI and DICOM inputs, safety rejection cases, and dataset manifest integration tests. |
| Phase 3 preprocessing and QC | [Preprocessing recipes](PREPROCESSING.md), provenance, registration and skull-mask adapters, optional N4, cache, JSON reports, and QC montages | Synthetic geometry and intensity checks, seeded replay, cache isolation, N4 smoke test, and QC failure cases. |
| Phase 4 baseline segmentation | [2D and 3D U-Nets](BASELINE_TRAINING.md), configurable training and losses, checkpoints, and overlap and surface metrics | Synthetic training, exact CPU checkpoint replay, CPU BF16, schedule and stopping behavior, and analytic metric tests. MRI metrics are not yet benchmarked. |
| Phase 5 advanced model zoo | [Modular architectures](../research/MODEL_ZOO.md), factory and registry, checkpoint manager, inference, and parameter/profiling reports | Synthetic architecture forward/backward checks, training integration, checkpoint reconstruction, and inference contracts. MRI metrics remain not yet benchmarked. |
| Phase 6 ensemble intelligence | [Weighted ensembles and NeuroConfidence](../research/ENSEMBLE_INTELLIGENCE.md), TTA, uncertainty statistics, supported MC dropout, and a local interactive viewer | Analytic probability checks, TTA inversion, seeded sampling and state restoration, and offline viewer control tests. Browser layout verification is pending. |
| Phase 7 explainability and NeuroMap | [Fixed-ROI gradient and occlusion experiments, atlas overlap, volumetry, and comparison reports](../research/NEUROMAP.md) | Analytic sensitivity and asymmetric atlas checks, physical volume on sheared geometry, and report generation on synthetic inputs. External atlas alignment and MRI benchmarking remain unverified. |
| Phase 8 longitudinal mapping | [NeuroTimeline](../research/NEUROTIMELINE.md) compares native regional volumes and registered masks, with optional paired replicate spread. | Synthetic rigid translation, shared coverage, physical units, replicate pairing, and offline viewer controls. Real MRI performance and registration estimation remain unverified. |
| Phase 9 backend platform | [FastAPI service](../api/README.md) with versioned routes, local queued jobs, upload safeguards, and replaceable service adapters. | Synthetic end-to-end HTTP workflows, authorization isolation, request quotas, job failures and artifact exports. Distributed deployment remains pending. |
| Phase 10 web experience | [React research workspace](WEB_WORKSPACE.md), tri-planar viewer, overlays, sampled 3D preview, connected research pages, and a guided synthetic case. | Browser checks cover desktop and mobile workflows and synthetic API upload, preprocessing, and inference. Live longitudinal visualization remains available through the Python workflow. |
| Phase 11 research reporting | [Structured research reports](../research/REPORTING.md), frozen artifact snapshots, volumetry and reproducibility metadata, JSON/HTML, and optional PDF export. | Synthetic report integrity, missing-field and escaping checks, PDF text and layout inspection, owner isolation, and connected web downloads. |
| MRI processing, models, and application | Planned for later phases | Validation will be defined with each implementation. |
| Final PDF and PowerPoint | Planned after implementation phases are merged | Check the artifacts against the merged project. |
